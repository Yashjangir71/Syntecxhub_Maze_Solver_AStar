Meaning of Symbols
| Symbol | Meaning               |
| ------ | --------------------- |
| `S`    | Start Position        |
| `G`    | Goal Position         |
| `.`    | Empty Cell (Walkable) |
| `#`    | Wall (Obstacle)       |
